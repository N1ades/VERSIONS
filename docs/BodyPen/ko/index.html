BodyPen — VRChat 아바타에 손가락으로 그림 그리기

BOOTH에서 보기 ↗

손가락으로 아바타에 직접 그려 보세요. BodyPen은 VRChat 아바타의 몸과 의상 표면에 그림을 그리는 기믹입니다. 머리 옆 팔레트를 터치해 색을 고르고 검지로 그릴 수 있습니다. 지우개로 일부를 지우거나 메뉴에서 전체 그림을 지울 수 있습니다. Windows PC / PC VR용입니다. Material Contacts를 지원하는 클라이언트와 SDK가 필요합니다. 테스트 환경은 VRChat Open Beta를 사용합니다. 구매 전에 요구 사항을 확인해 주세요.

주요 기능

• Unity에서 변경할 수 있는 7가지 색상과 지우개. 설정한 색상이 팔레트에도 반영됩니다. • 자신과 다른 사용자의 그리기 및 팔레트 조작 권한을 각각 설정할 수 있습니다. VRChat의 Contact 권한도 적용됩니다. • 불투명도, 거칠기, 금속성, 조명, 발광, 텍스처와 Grain을 조절할 수 있습니다. • Spray droplets는 원래 선을 유지하며 일부 물방울이 아래로 흐릅니다. Physical Gravity Flow는 페인트 자체를 이동시킵니다. 두 모드는 동시에 사용할 수 없습니다. • 시간이 지나면 사라지는 Lifetime, 초기 그림 텍스처, 그리기 일시 정지를 지원합니다. • NDMF / Modular Avatar로 최대 16개 메시를 설정합니다. 원본 메시와 머티리얼 에셋은 유지됩니다. • Inspector와 아바타 메뉴는 영어 / 일본어 / 한국어 / 러시아어를 지원합니다. • Hide palette로 팔레트를 숨겨도 메뉴의 색상 선택과 그리기를 사용할 수 있습니다.

요구 사항

• Windows PC / PC VR, Built-in Render Pipeline. Quest / Android는 지원하지 않습니다. • Unity 2022.3.22f1. • Material Contacts를 지원하는 VRChat Base 및 Avatars SDK, Modular Avatar, NDMF. • 호환되는 VRChat 클라이언트. 테스트 환경은 Open Beta를 사용합니다. • UV0와 삼각형 서브메시가 있는 대상 메시. MeshRenderer와 SkinnedMeshRenderer를 지원합니다. 테스트 버전: SDK 3.10.6-beta.2 / Modular Avatar 1.19.0-alpha.2 / NDMF 1.15.0-beta.2. 이는 개발 환경 버전이며 이전 안정 버전의 호환성을 보장하지 않습니다. Material Contacts가 없으면 패키지 관리 도구에서 프리릴리스 표시를 켜고 Base와 Avatars를 모두 업데이트해 주세요.

설치 및 사용 방법

1. 다운로드한 ZIP을 풀고 아바타 프로젝트에 unitypackage를 임포트합니다. 2. BodyPen.prefab을 아바타 아래에 배치합니다. 또는 아바타를 선택한 뒤 Tools → Nyades → BodyPen → Add to selected avatar를 실행합니다. 3. Inspector의 Meshes 목록에 그릴 메시를 1~16개 추가합니다. 4. 머리를 기준으로 팔레트 위치를 맞추고 7가지 색상, 브러시 크기, 지우개 크기를 설정합니다. 빌드 시 팔레트가 Head 본을 따라갑니다. 5. 일반 VRChat SDK 절차로 빌드 및 업로드한 뒤 호환되는 클라이언트에서 확인합니다. 검지로 팔레트를 터치해 색상이나 지우개를 선택하고 대상 메시를 터치합니다. 메뉴에서 그리기 권한, Clear, Hide palette를 사용할 수 있습니다. 다른 사용자와 상호작용하려면 VRChat의 해당 Contact 권한도 켜 주세요.

호환성 및 제한 사항

• 도구와 제어 파라미터는 동기화되지만 페인트 기록은 각 클라이언트에서 따로 누적됩니다. 나중에 입장한 사용자는 이전 그림을 받지 못합니다. 픽셀 단위로 동일한 이미지 동기화는 제공하지 않습니다. • UV 경계, 의상, 셰이더, 카메라 구성에 따라 결과가 달라질 수 있으므로 아바타별 조정이 필요합니다. • 추가 캡처와 GPU 메모리를 사용합니다. Performance에서 하나의 공유 아틀라스 해상도를 1024 / 2048 / 4096 / 8192 중 선택합니다. Lifetime과 Physical Gravity Flow는 추가 페인트 버퍼를 사용합니다. • 거울을 지원합니다. 직교 카메라와 VRChat 사진/UI 카메라는 그리기 처리 대상에서 제외됩니다. • 동일한 아바타 복사본끼리 셰이더 전송 이름을 공유해 서로 간섭할 수 있습니다. • 모든 아바타, 셰이더, 안정 버전 클라이언트 및 이전 SDK와의 호환성을 보장하지 않습니다.

상품 구성

BodyPen 프리팹, 컴파일된 DLL, 페인팅 셰이더, 영어/일본어 가이드. 아바타 모델과 의상은 포함되지 않습니다. 소스 코드는 제공하지 않습니다.

버전

현재 BOOTH 첨부 파일은 개발 버전 0.9.2입니다. 공개 출시 시 1.0.0으로 전환할 예정입니다. 최신 파일과 판매 상태는 BOOTH에서 확인해 주세요.

이용 조건 및 문의

구매자 본인의 VRChat 아바타에 사용할 수 있습니다. 도구, 설치 파일, unitypackage, DLL의 재배포, 공유 및 재판매는 금지됩니다. 아바타, 의상, 셰이더 등 타사 에셋의 이용 조건도 준수해 주세요. 배포된 빌드가 비활성화된 경우 공식 상품 페이지에서 최신 사본을 다운로드해 주세요. 문의나 오류는 BOOTH 메시지 또는 Discord로 연락해 주세요. Unity, SDK, BodyPen 버전과 오류 화면을 함께 보내 주시면 도움이 됩니다.
