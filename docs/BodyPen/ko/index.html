첫날 세일: 11월 1일(JST)까지 40% OFF VRChat 아바타에 직접 그려 보세요. BodyPen은 VRChat 아바타의 몸과 의상 표면에 그림을 그리는 기믹입니다. 팔레트를 터치해 색을 고르고 검지 또는 호환되는 Contact로 그릴 수 있습니다. 지우개로 일부를 지우거나 메뉴에서 전체 그림을 지울 수 있습니다.

주요 기능

■ 그리기 ✔ 손가락이나 호환되는 Contact로 내 아바타와 BodyPen이 있는 다른 아바타에 직접 그려 보세요. ✔ 처음 만난 사람과도 사용 가능: 다른 플레이어가 BodyPen을 설치하지 않아도 그림을 볼 수 있고 내 아바타에 그릴 수 있습니다. ✔ 함께 그리기: 최대 8개의 동시 터치 지점을 지원합니다. ■ 제어 ✔ 권한을 관리하세요: 누가 그릴 수 있는지, 어떤 Contact를 허용할지 설정합니다. ✔ 보호할 부분을 마스크로 지정합니다. ✔ 간편한 설치: NDMF와 Modular Avatar로 동작합니다. ✔ 인터페이스는 영어, 일본어, 한국어, 러시아어를 지원합니다. ■ 페인트 ✔ 색상, 브러시 크기, 페인트 속성을 조절하세요. ✔ Lifetime: 시간이 지나면서 페인트가 서서히 사라집니다. ✔ Physical Gravity Flow: 페인트 자체가 표면을 따라 아래로 흘러내립니다. ✔ 커스텀 셰이더 지원: 텍스처를 지원하는 모든 머티리얼에 추가할 수 있습니다. ■ 실험적 기능 ✔ 플레이어별 색상: 그리는 사람마다 색상, 밝기, 브러시 크기, 지우개를 개별적으로 설정할 수 있습니다. ✔ 성능 조절: VeryPoor 등급 아바타를 위한 고품질 설정 또는 Good 등급을 목표로 한 최대 최적화 설정을 선택할 수 있습니다.

요구 사항

• VRChat SDK 3.10.6 이상 • Modular Avatar

설치 및 사용 방법

설치

1. 다운로드한 ZIP을 풀고 아바타 프로젝트에 unitypackage를 임포트합니다. 2. VRChat SDK 3.10.6 이상을 설치합니다(출시 시점에는 베타). Gesture Manager 또는 Av3Emulator를 권장합니다.

BodyPen 추가와 팔레트 배치

3. “Hierarchy”에서 아바타를 우클릭하고 메뉴에서 “BodyPen”을 선택합니다. 4. “Palette” 오브젝트를 선택하고 원하는 신체 부위 위치로 옮깁니다. 5. 팔레트가 따라갈 본은 “MA Bone Proxy”에서 선택합니다. 기본값은 “Head”입니다.

메시 선택

6. “BodyPen” 프리팹에서 “대상 메시”를 선택합니다. 7. 그림을 그릴 메시를 여기에 드래그 앤 드롭합니다. 8. 일부 머티리얼 슬롯은 그리기에서 제외할 수 있습니다. 9. UV 아일랜드나 지오메트리를 제외하려면 “마스크”를 켜고 “검정”을 선택한 뒤 그리고 싶지 않은 부분을 클릭합니다. 해당 부분이 빨갛게 표시됩니다. 10. “편집”을 클릭하면 마스크 편집이 끝납니다.

브러시와 색상 조정

11. “브러시”에서 “Play Mode에서 테스트”를 클릭하고, Game 뷰에서 아바타에 그려 보며 브러시 설정을 조정합니다. 12. “색상 팔레트”에서 색상을 조정합니다. 13. Play Mode에서 바꾼 값을 유지하려면 “Unity Play Mode”의 “컴포넌트에 값 저장”을 켭니다. 14. “페인트 머티리얼”에서 페인트의 외형, 지속 시간, 텍스처를 바꿀 수 있습니다.

호환성 및 제한 사항

• 페인트 기록은 각 클라이언트에서 따로 누적됩니다. 나중에 입장한 사용자는 이전 그림을 받지 못합니다. • 동일한 아바타 복사본끼리 셰이더를 통한 데이터 전송에 같은 이름을 사용해 서로 간섭할 수 있습니다. • 모든 아바타, 셰이더, 안정 버전 클라이언트 및 이전 SDK와의 호환성은 보장하지 않습니다. 오류가 있으면 BOOTH 또는 Discord로 연락해 주세요.
