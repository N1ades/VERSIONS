BodyPen — VRChat 아바타에 손가락으로 그림 그리기

BOOTH에서 보기 ↗

손가락으로 아바타에 직접 그려 보세요. BodyPen은 VRChat 아바타의 몸과 의상 표면에 그림을 그리는 기믹입니다. 머리 옆 팔레트를 터치해 색을 고르고 검지로 그릴 수 있습니다. 지우개로 일부를 지우거나 메뉴에서 전체 그림을 지울 수 있습니다. Windows PC / PC VR용입니다. Material Contacts를 지원하는 클라이언트와 SDK가 필요합니다. 테스트 환경은 VRChat Open Beta를 사용합니다. 구매 전에 요구 사항을 확인해 주세요. 첫날 세일: 11월 1일(JST)까지 ¥1,200. 이후 정가 ¥2,000.

주요 기능

■ 그리기 ✔ 손가락이나 호환되는 Contact로 내 아바타와 BodyPen이 있는 다른 아바타에 직접 그려 보세요. ✔ 처음 만난 사람과도 사용 가능: 다른 플레이어가 BodyPen을 설치하지 않아도 그림을 볼 수 있고 내 아바타에 그릴 수 있습니다. ✔ 함께 그리기: 최대 8개의 동시 터치 지점을 지원합니다. ■ 컨트롤 ✔ 권한을 관리하세요: 누가 그릴 수 있는지, 어떤 Contact를 받을지 설정합니다. 자신과 다른 사용자의 그리기 및 팔레트 조작 권한을 각각 설정할 수 있으며 VRChat의 Contact 권한도 적용됩니다. ✔ 그릴 수 있는 곳을 선택하세요: 필요한 메시를 추가(최대 16개)하고 보호할 부분은 마스크로 지정합니다. ✔ 지우개로 지우거나 메뉴에서 전체를 지우세요. 팔레트를 숨겨도 메뉴에서 색상 선택과 그리기를 사용할 수 있습니다. ■ 페인트 ✔ 색상, 브러시 크기, 페인트 속성을 조절하세요. ✔ 시간이 지나면 페인트가 사라지게 설정하세요. ✔ 직접 만든 셰이더에서도 사용하세요: 텍스처를 지원하는 다른 머티리얼에 바로 통합할 수 있습니다. ✔ 흐르는 페인트를 켜세요: 페인트가 표면을 따라 아래로 흘러내립니다. ■ 실험적 기능 ✔ 플레이어마다 다른 색상: 그리는 사람마다 독립된 색상, 밝기, 브러시 크기, 지우개를 사용합니다. Lifetime과 Physical Gravity Flow는 꺼 주세요. ✔ 성능을 유연하게 조절하세요: VeryPoor 아바타용 고품질 또는 Good 유지를 위한 최대 최적화를 선택할 수 있습니다. ■ 설치 ✔ 번거로움 없이 설치: 원본 메시와 머티리얼은 유지되며 NDMF와 Modular Avatar가 빌드 시 자동으로 설정합니다. ✔ Inspector와 아바타 메뉴는 영어 / 일본어 / 한국어 / 러시아어를 지원합니다.

요구 사항

• Windows PC / PC VR, Built-in Render Pipeline. Quest / Android는 지원하지 않습니다. • Unity 2022.3.22f1. • Material Contacts를 지원하는 VRChat Base 및 Avatars SDK, Modular Avatar, NDMF. • 호환되는 VRChat 클라이언트. 테스트 환경은 Open Beta를 사용합니다. • UV0와 삼각형 서브메시가 있는 대상 메시. MeshRenderer와 SkinnedMeshRenderer를 지원합니다. 테스트 버전: SDK 3.10.6-beta.2 / Modular Avatar 1.19.0-alpha.2 / NDMF 1.15.0-beta.2. 이는 개발 환경 버전이며 이전 안정 버전의 호환성을 보장하지 않습니다. Material Contacts가 없으면 패키지 관리 도구에서 프리릴리스 표시를 켜고 Base와 Avatars를 모두 업데이트해 주세요.

설치 및 사용 방법

1. 다운로드한 ZIP을 풀고 아바타 프로젝트에 unitypackage를 임포트합니다. 2. VRChat SDK 3.10.6 이상을 설치합니다(촬영 시점에는 베타). Gesture Manager는 선택 사항입니다. 3. “Hierarchy”에서 아바타를 우클릭하고 메뉴에서 “BodyPen”을 선택합니다. (또는 Tools → Nyades → BodyPen → Add to selected avatar.) 4. “Palette” 오브젝트를 선택하고 원하는 신체 부위 위치로 옮깁니다. 5. 팔레트가 따라갈 본을 선택합니다. 기본값은 “Head”입니다. 6. “BodyPen” 프리팹을 선택하고 “대상 메시”를 엽니다. 7. 그리고 싶은 메시를 추가합니다. 먼저 얼굴 메시를 추가하세요. 8. 메시의 일부만 그릴 수 없게 할 수 있습니다. 예를 들어 “body_options”는 표정 효과용이므로 꺼서 그려지지 않게 합니다. 9. 눈을 보호하려면 “마스크”를 켜고 “검정”을 선택한 뒤 그리고 싶지 않은 부분을 클릭합니다. 해당 부분이 빨갛게 표시됩니다. “편집”을 클릭하면 마스크 편집이 끝납니다. 10. 나머지 메시(몸, 의상, 머리카락 등, 최대 16개)를 추가합니다. 11. “브러시”에서 “Play Mode에서 테스트”를 클릭해 선택한 메시에 그려 보며 브러시 설정을 조정합니다. 12. “색상 팔레트”에서 색상을 조정합니다. 13. Play Mode에서 바꾼 값을 유지하려면 “Unity Play Mode”의 “컴포넌트에 값 저장”을 켭니다. 14. “페인트 머티리얼”에서 페인트의 외형, 지속 시간, 텍스처를 바꿀 수 있습니다. 15. 준비 완료! 아바타를 빌드·업로드하고 그려 보세요. 검지로 팔레트를 터치해 색상이나 지우개를 선택하고 대상 메시를 터치합니다. 메뉴에서 그리기 권한, Clear, Hide palette를 사용할 수 있습니다. 다른 사용자와 상호작용하려면 VRChat의 해당 Contact 권한도 켜 주세요.

호환성 및 제한 사항

• 도구와 제어 파라미터는 동기화되지만 페인트 기록은 각 클라이언트에서 따로 누적됩니다. 나중에 입장한 사용자는 이전 그림을 받지 못합니다. 픽셀 단위로 동일한 이미지 동기화는 제공하지 않습니다. • UV 경계, 의상, 셰이더, 카메라 구성에 따라 결과가 달라질 수 있으므로 아바타별 조정이 필요합니다. • 추가 캡처와 GPU 메모리를 사용합니다. Performance에서 하나의 공유 아틀라스 해상도를 1024 / 2048 / 4096 / 8192 중 선택합니다. Lifetime과 Physical Gravity Flow는 추가 페인트 버퍼를 사용합니다. • 거울을 지원합니다. 직교 카메라와 VRChat 사진/UI 카메라는 그리기 처리 대상에서 제외됩니다. • 동일한 아바타 복사본끼리 셰이더 전송 이름을 공유해 서로 간섭할 수 있습니다. • 모든 아바타, 셰이더, 안정 버전 클라이언트 및 이전 SDK와의 호환성을 보장하지 않습니다.

상품 구성

BodyPen 프리팹, 컴파일된 DLL, 페인팅 셰이더, 영어/일본어 가이드. 아바타 모델과 의상은 포함되지 않습니다. 소스 코드는 제공하지 않습니다.

이용 조건 및 문의
