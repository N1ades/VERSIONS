Nyades FT — VRChat용 데스크톱 페이스 트래킹

▍Nyades FT란 웹캠 하나로 VRChat에 당신의 표정을. Nyades FT는 Windows PC에 연결된 웹캠으로 얼굴 움직임을 읽고, OSC를 통해 표정 파라미터를 VRChat에 직접 전송합니다. VRCFT 형식의 파라미터를 따르므로 페이스 트래킹이 설정된 아바타에서 바로 사용할 수 있습니다. VRCFaceTracking을 실행할 필요가 없습니다. 지원 플랫폼: Windows 10 / 11 (x64), Linux β (x86_64 AppImage, WebKitGTK 4.1 필요) ▍무료 체험판과 정식 버전 ・무료 체험판: 실행할 때마다 10분 동안 페이스 트래킹을 전송합니다. 먼저 사용 환경에서 확인해 보세요. ・정식 버전: 시간 제한 없음, 인터페이스 색상 커스터마이즈 포함. ▍주요 기능 ✔ 표정뿐 아니라 시선과 혀도 트래킹 ✔ Windows에서 GPU 가속 (카메라·얼굴·혀 처리마다 Auto, CPU, GPU 선택) ✔ 캘리브레이션으로 어떤 얼굴에서도 완벽한 표정 캡처. 자동·수동 모드, 파라미터별 여러 캡처 모드, 스무딩과 대칭, 그리고 고급 사용자를 위한 노드 방식 Expression Mapping 에디터. ✔ VRChat Open Beta의 Native Face Tracking 지원 ✔ 영상은 PC에서 처리되며 업로드되지 않습니다 ✔ 인터페이스 색상 커스터마이즈 (정식 버전: 프리셋 6종, 컬러 피커). 덤으로 미리보기에 고양이 귀도 표시할 수 있습니다. 둘 다 Nyades FT의 외형만 바꾸며 VRChat 아바타에는 영향을 주지 않습니다.

시작하기

▍필요한 것 ・웹캠 ・VRCFT (Unified Expressions) 또는 VRChat Native Face Tracking을 지원하는 아바타 (Nyades FT는 아바타를 설정하지 않습니다) ▍처음 사용하기 ① ZIP을 다운로드하고 압축을 풉니다. ② 압축을 푼 exe를 실행합니다. ③ 카메라를 선택하고 얼굴이 화면에 보이도록 합니다. ④ VRChat에서 OSC를 켜고 호환되는 아바타를 선택합니다. ⑤ 정면을 보고 얼굴의 힘을 뺀 뒤 「무표정 저장」을 누릅니다. 이어서 「시선 중앙 맞추기」로 시선을 조정합니다. 필요하면 표정 파라미터를 직접 보정하세요. ※ 업데이트는 앱 안에서 설치할 수 있습니다 (톱니바퀴 → 업데이트). ▍VRChat 상체 카메라 트래킹과 함께 사용하기 머리·상체·손도 움직이려면 아래 중 하나를 설정하세요. 가상 카메라(방법 1)를 추천합니다: ✓ VRChat 자체 얼굴 인식이 Nyades FT의 페이스 트래킹 위에 표정을 겹치지 않습니다 ✓ 얼굴이 마스크로 가려져 VRChat에 맨얼굴이 보이지 않습니다 ✓ Windows 설정을 바꿀 필요가 없습니다 ▶ 방법 1 — 가상 카메라 (추천·실험적) 　① Nyades FT 　　└ 입력 카메라로 실제 웹캠을 선택 　　└ 설정 → 「가상 카메라 (OBS, 실험적)」 → 「설치 및 활성화」 　② VRChat 　　└ 설정 → 트래킹 및 IK → 카메라로 「OBS Virtual Camera」 선택 　　└ 「Selfie Expression 활성화」를 켭니다 ▶ 방법 2 — 카메라 동시 사용 허용 　가상 카메라가 잘 동작하지 않을 때 사용하세요. 　① Windows 설정 　　└ Bluetooth 및 장치 → 카메라 → 사용할 카메라 　　└ 고급 카메라 옵션 → 편집 　　└ 「여러 앱의 카메라 동시 사용 허용」을 켬 → 적용 　② VRChat 　　└ 메인 메뉴 → 설정 → 트래킹 및 IK 　　└ 「Selfie Expression 활성화」를 켭니다 → 손 트래킹은 어느 방법이든 「Selfie Expression Also Moves Hands」를 켜세요. ※ 카메라를 사용할 수 없다면 Windows의 카메라 권한과 다른 앱이 사용 중인지 확인하세요.
