About Stocking Pull

Pinch the fabric, pull it, and repair it from your avatar menu.

Stocking Pull is a Modular Avatar add-on for VRChat. Grab the fabric with a PhysBone and it stretches from the point you pinched as you move your hand. Pull hard enough to tear it and the tear stays when you let go.

Features

  • The avatar wearer and other players with grab permission can interact. Choose 1–8 simultaneous grabs. The default maximum stretch is 6 cm.
  • The avatar menu includes Pull, Repair, Self Pull, and Sound. Repair clears tears and cancels held pulls. Sound appears when sound effects are enabled.
  • Use a stocking material layered over the body, or select material slots on an existing skinned garment. Supports lilToon and Poiyomi.
  • Use Pull Blockers where the fabric should resist stretching. Replace the five cloth sounds for pinching, stretching, tearing, releasing, and repairing, and adjust their volume.

Requirements and setup

  1. In your avatar’s Unity project, install the VRChat Avatars SDK with Material Contacts (developed with 3.10.6), Modular Avatar, NDMF, the Nyades Shared Editor assembly, and lilToon or Poiyomi. Import the Stocking Pull unitypackage.
  2. For a body overlay, add Stocking Pull (Modular Avatar) under your avatar. Assign the body renderer and set up a stocking texture and opacity mask that fit your avatar’s UVs.
  3. For an existing garment, add Stocking Pull Setup to the skinned mesh, enable Use Existing Material, and select the Material Slots to use. This mode keeps the garment’s existing textures.
  4. Set the pull regions and simultaneous grab count. Adjust blockers and sound as needed, then check the result in Unity Play Mode before building.

Before buying and support

The body overlay needs a texture and mask fitted to your avatar. Grabs follow VRChat’s interaction settings. For questions or bug reports, send a BOOTH message with your Unity, SDK, and shader versions and steps to reproduce the issue.
