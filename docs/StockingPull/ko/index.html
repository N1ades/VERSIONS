Stocking Pull 소개

천을 잡아당기고, 찢어지면 아바타 메뉴에서 복구하세요.

VRChat 아바타용 Modular Avatar 기믹입니다. PhysBone으로 천을 잡으면 잡은 지점을 중심으로 손의 움직임에 따라 천이 늘어납니다. 세게 당겨 천이 찢어지면 손을 놓은 뒤에도 찢어진 자국이 남습니다.

주요 기능

  • 아바타를 사용하는 본인과 잡기가 허용된 다른 플레이어가 사용할 수 있습니다. 동시 잡기 수는 1~8개로 설정할 수 있으며, 기본 최대 늘어나는 길이는 6 cm입니다.
  • 아바타 메뉴에서 Pull, Repair, Self Pull, Sound를 사용할 수 있습니다. Repair는 찢어진 자국을 지우고 진행 중인 당기기를 취소합니다. 효과음을 활성화하면 Sound가 표시됩니다.
  • 몸 위에 스타킹용 머티리얼을 덧씌우거나, 기존 스킨드 의상의 머티리얼 슬롯을 선택해 사용할 수 있습니다. lilToon과 Poiyomi를 지원합니다.
  • Pull Blockers로 천이 늘어나지 않도록 할 위치를 지정할 수 있습니다. 잡기, 늘어나기, 찢어지기, 놓기, 복구에 쓰이는 다섯 가지 효과음을 교체하고 볼륨을 조절할 수 있습니다.

필요한 항목과 설치 방법

  1. 아바타의 Unity 프로젝트에 Material Contacts를 지원하는 VRChat Avatars SDK(개발 환경은 3.10.6), Modular Avatar, NDMF, Nyades Shared의 Editor 어셈블리와 lilToon 또는 Poiyomi를 설치한 뒤 Stocking Pull unitypackage를 임포트합니다.
  2. 몸 위에 덧씌우려면 아바타 아래에 Stocking Pull (Modular Avatar)를 추가합니다. 몸의 Renderer를 지정하고 아바타 UV에 맞는 스타킹 텍스처와 불투명도 마스크를 설정합니다.
  3. 기존 의상을 사용하려면 의상의 스킨드 메시에서 Stocking Pull Setup을 추가하고 Use Existing Material을 켠 뒤 Material Slots를 선택합니다. 이 모드에서는 의상의 기존 텍스처를 사용합니다.
  4. 당길 수 있는 영역과 동시 잡기 수를 설정합니다. 필요한 경우 Pull Blockers와 효과음을 조절하고 빌드 전에 Unity Play Mode에서 확인합니다.

구매 전 확인 및 문의

몸 위에 덧씌우는 방식에는 아바타 UV에 맞는 텍스처와 마스크가 필요합니다. 잡기 권한은 VRChat의 상호작용 설정을 따릅니다. 질문이나 오류 제보는 Unity, SDK, 셰이더 버전과 재현 방법을 적어 BOOTH 메시지로 보내 주세요.
