Nyades - Stocking Pull

BOOTH에서 보기 ↗

VRChat에서 스타킹이나 소매를 잡아당겨 천을 찢을 수 있는 기믹입니다. 아바타 메뉴의 Repair를 누르면 복구됩니다.

주요 기능

■ 친구와 함께 당기기
✔ 기본 설정에서는 두 곳을 동시에 당길 수 있습니다. 최대 8곳까지 늘릴 수 있습니다.

■ ASMR처럼 들리는 찢김 소리
✔ 스타킹의 실이 뜯어지는 소리를 들어 보세요. 올이 풀릴 때, 천을 놓을 때, 복구할 때의 소리는 교체할 수 있습니다.

■ 오래 당길수록 커지는 찢김
✔ 천을 팽팽하게 당긴 채로 유지하면 찢어진 부분이 더 커집니다.

■ 기존 머티리얼 위에 적용
✔ lilToon이나 Poiyomi를 사용하는 몸과 의상의 스킨드 메시에 적용할 수 있습니다. 천 레이어는 기존 메시의 삼각형을 그대로 사용합니다.

■ 같은 곳을 다시 찢어 구멍 넓히기
✔ 이미 찢어진 곳을 다시 잡아당기면 구멍이 조금씩 넓어집니다.

■ 당김을 제한하는 밴드
✔ 다리에 두른 밴드를 ‘당김 차단 오브젝트’에 추가하면 스타킹을 잡아당겨도 밴드는 제자리에 있고 주변의 천이 늘어납니다.

■ 늘어남과 찢김의 모양
✔ 손끝에서 천이 늘어나는 범위와 당겼을 때의 투명도, 광택을 조절할 수 있습니다. 찢어진 부분의 길이와 폭, 가장자리 모양, 풀린 실, 가까운 찢김이 이어지는 정도도 바꿀 수 있습니다.

■ 찢김 동기화
✔ 다른 플레이어에게도 같은 찢김이 보입니다. 손을 놓아도 찢어진 자국은 그대로 남습니다.

요구 사항

• VRChat Avatars SDK 3.10.6 이상 • Modular Avatar • 의상 머티리얼에는 Poiyomi 10 이상 또는 lilToon 2.4.1 이상 중 하나를 사용하세요. • 선택 사항: Unity에서 테스트할 때 사용하는 Gesture Manager

설치 및 사용 방법

설치

1. 아바타 프로젝트에 Stocking Pull의 .unitypackage를 임포트하세요.

Stocking Pull 추가

2. Hierarchy에서 Skinned Mesh Renderer가 있는 의상을 우클릭하고 Nyades → Stocking Pull → Add Component를 선택하세요.

메시 선택

3. ‘메시’에서 천 머티리얼을 켜세요. 찢어지면 안 되는 부분은 ‘찢김 방지’에서 마스크로 지정하세요.
스타킹이 몸 텍스처에 그려져 있다면 몸 UV에 맞는 스타킹 텍스처와 투명도 마스크로 별도의 머티리얼을 준비하세요. 몸 메시에 컴포넌트를 추가하고 ‘메시’에서 스타킹 슬롯만 켜세요. 머티리얼 행을 펼치면 ‘셸 오프셋’으로 몸과 스타킹 사이의 간격을 밀리미터 단위로 조절할 수 있습니다.

당김과 찢김 조정

4. 천을 덮는 옷을 ‘당김 차단 오브젝트’에 추가하고 ‘마스크 미리보기’로 범위를 확인하세요.
5. ‘스타킹 당김’ → ‘잡을 수 있는 부위’에서 의상이 덮는 부위를 선택하세요. ‘접촉 범위 미리 보기’를 켜고 캡슐이 천을 덮도록 ‘접촉 여유 거리’를 조절하세요.
6. ‘플레이 모드에서 테스트’를 누르고 Game 뷰에서 마우스 왼쪽 버튼으로 천을 드래그하세요. 변경 사항을 유지하려면 종료 전에 ‘컴포넌트에 저장’을 누르세요.

호환성 및 제한 사항

• Meta Quest 단독 실행 환경(Android)에서는 Stocking Pull 셰이더 효과가 표시되지 않아 천이 늘어나거나 찢어지는 모습이 보이지 않습니다. • 다른 플레이어가 옷을 잡을 수 있는지는 VRChat 상호작용 설정에 따릅니다. • 자기 옷을 잡으려면 Self Pull을 켜세요. • 12개 부위 중 의상이 덮는 곳만 활성화할 수 있습니다. • ‘성능’ → ‘측정’에서 적용 전후의 PC 아바타 성능 등급을 비교할 수 있습니다.

이용 조건 및 문의

이용 조건

구매자 본인의 VRChat 아바타에 사용할 수 있습니다. 도구, 아바타에 설치된 파일, unitypackage, DLL의 재배포, 공유 및 재판매는 금지됩니다. 아바타, 의상, 셰이더 등 타사 에셋의 이용 조건도 준수해 주세요.

아바타 배포용 베이크

Stocking Pull을 적용한 아바타를 배포하려면 ‘베이크 (선택 사항)’에서 ‘잠금’을 누르세요. 아바타 프리팹, 베이크된 에셋, 구동에 필요한 Lock Support DLL을 함께 제공하세요. 편집용 패키지와 잠금 해제에 쓰는 백업은 제작자 프로젝트에 보관하세요.
